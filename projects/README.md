# Найденные проекты — рабочая база

Пять публичных проектов, доказанных в ходе работы над каталогом продукции
(проверено 2026-09-02). Источники: страницы проектов на oshwlab/easyeda,
список репозиториев github.com/shadowlamer, раздел easyeda explore,
локальный экспорт EasyEDA (`~/git/test/elec/`). Метрики зафиксированы на
дату проверки.

заглушки), данные взяты с explore-страниц.
