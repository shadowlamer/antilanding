# USB-MDB converter

Конвертер протокола MDB (Multi-Drop Bus, шина вендинговых автоматов)
в USB. По описанию GitHub-репозитория: «open-source hardware and software
solution… designed for vending machine integration, device emulation,
and data analysis».

## Временной период

- 20.02.2020 19:10 — разведена плата (дата в имени PCB-файла экспорта;
  совпадает с датой создания проекта на oshwlab).
- 14.03.2022 — последнее обновление проекта на oshwlab.
- 27.01.2025 — последнее обновление GitHub-репозитория.

## Стек

- МК: STM32F103C8T6 (5 вхождений в JSON экспорта)
- Интерфейсы: MDB (slave-шина вендинга) ↔ USB
- Прошивка: C (репозиторий MDB-USB-adapter)
