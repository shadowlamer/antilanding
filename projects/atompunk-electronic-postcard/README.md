# Atompunk electronic postcard (sixties)

Электронная открытка в стиле шестидесятых. По описанию GitHub-репозитория:
«Electronic postcard based on STM32 and SPI LCD»; теги репо: fun, retro,
stm32, postcard, cyberpunk, coocox.

## Временной период

- 19.07.2018 — создан проект на oshwlab.
- 11.10.2018 — последнее обновление GitHub-репозитория.
- 09.10.2020 — последнее обновление проекта на oshwlab.

## Стек

- МК: STM32F030F4 (3 вхождения в JSON экспорта)
- Дисплей: SPI LCD
- Прошивка: C, IDE CooCox (по тегам репозитория)
- Механика: чертежи DXF приложены к публикации
