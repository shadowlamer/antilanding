# Low-speed pixel poi

Светодиодные пои: прозрачные трубки с лентами адресных светодиодов,
аккумулятор 18650, SD-карта. Авторское описание умещается в одну строку:
«Low-speed, high resolution pixel poi based on WS2812B LED strip».
На фото пои выключены.

## Временной период

- Публикация на EasyEDA ~2018 (на explore отображается «7 years ago»,
  проверено 02.09.2026).
- Прошивка на GitHub обновлялась до 17.02.2020.
- По летописи (TIMELINE.md) — EasyEDA-поколение пои 2017–2022; ему
  предшествовали «мегапои» 2016 (hdpoi/ldpoi, механика в SketchUp/DXF)
  и светокостюмы ledjoy 2012–2014.

## Стек

- МК: STM32F030F4 / STM32F030F4P6 (из схемы экспорта)
- Светодиоды: WS2812B; питание: аккумулятор 18650; хранение: SD-карта
- Прошивка: C — репозиторий spi_poi_firmware
- САПР: EasyEDA
