# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

«Антилендинг» — персональный сайт Вадима Черенёва (разработка электроники, Пермь). Размещён на GitHub Pages: `https://shadowlamer.github.io/antilanding/`. Форма — продающий лендинг, содержание — правдивое и с самоиронией. Это осознанная концепция, а не черновик.

**Тон — часть спецификации.** Шутки («от 0 ₽», «до ∞», «дендрофекальный метод», «Нет смысла со мной связываться») не «чинить» в маркетинговый язык. Факты (даты, стеки, числа, названия проектов) — только от автора; Claude делает верстку и черновики текстов (см. подпись в footer). Язык сайта — русский.

## Структура

Статический сайт без фреймворков, без сборки, без JS:

- `index.html` — единственная страница: секции нумеруются `[01]…[07]`, иконки — инлайн-SVG, метаданные — OG/Twitter-теги и JSON-LD Person с абсолютными URL `https://home.anhot.ru/…`.
- `style.css` — тёмная тема, все цвета — CSS-переменные в `:root` (`--bg`, `--nixie` = янтарный акцент, `--scope` = зелёный для ссылок).
- `img/nixie/` — фото никси-индикаторов (цифры `0 1 2 8 +`); повёрнутая на 90° «8» (`class="rot"`) читается как ∞. Показатели в секции [01] собираются из этих картинок.
- `llms.txt` — машинночитаемое резюме сайта для ИИ-краулеров. При изменении фактов в `index.html` синхронизировать с ним.
- `404.html` — страница 404 в теме сайта, со ссылкой на `/antilanding/`.

## Команды

Локальный просмотр (сервер нужен только для относительных путей и кэша):

```bash
python3 -m http.server 8000
```

Сборки нет — статика раздаётся как есть.

## Деплой — GitHub Pages

Адрес: `https://shadowlamer.github.io/antilanding/` (project pages, подпуть `/antilanding/`).

- Включение: Settings → Pages → Source: *Deploy from a branch* → ветка `main`, каталог `/ (root)`.
- `.nojekyll` отключает Jekyll-обработку — не удалять.
- Внутренние ссылки относительные и работают в подпути; **абсолютные URL в метатегах (`og:url`, `og:image`, `twitter:image`, canonical, JSON-LD `url`) обязаны содержать `/antilanding/`** — при смене хоста менять все.
- Ограничение project pages: `robots.txt`, `llms.txt`, `sitemap.xml` отдаются по `/antilanding/…`, а не из корня хоста — краулеры их не читают. Файлы оставлены на случай переезда на корневой хост.

### Устаревшее: self-host на docker

`Dockerfile`, `conf/nginx.conf`, `renew-cert.sh` — прежний деплой nginx+certbot на `home.anhot.ru`, после переезда на GitHub Pages не используется. Метатеги с `home.anhot.ru` уже заменены на github.io.
